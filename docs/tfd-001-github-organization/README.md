# TFD-001 — Bookamore → GitHub Organization

Slidev-презентація для команди про перехід `Dzheva/bookamore` з персонального
акаунта на повноцінну безкоштовну GitHub Organization.

## Перегляд локально

```bash
cd docs/tfd-001-github-organization
npm install
npm run dev
```

Відкриється на `http://localhost:3030`.

## Експорт у PDF

```bash
npm run export
```

## Вміст

- `slides.md` — сама презентація (плюси/мінуси, адміністрування, секрети,
  структура репозиторіїв, план міграції)

План міграції (кроки 4–8 у слайдах) незворотний — transfer репозиторію
виконується лише після явного підтвердження власника.
